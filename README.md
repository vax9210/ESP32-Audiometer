# ESP32 Audiometer

An experimental pure-tone audiometer built using ESP32 and Arduino.

## Overview

This project explores the development of a low-cost, ESP32-based audiometer for educational and experimental purposes.

The goal is to learn digital audio generation, embedded programming, and basic audiometric testing principles.

## Hardware

- ESP32 development board
- 0.96-inch OLED display (SSD1306, I2C)
- Audio output module
- Speaker

## Current Features

- Pure-tone signal generation
- Selectable test frequencies
- Warble-tone generation
- OLED display interface
- Adjustable digital output level

## Planned Features

- Independent left and right audio channels
- Headphone output
- Acoustic calibration
- Audiometric threshold testing
- Audiogram generation

## Development Environment

- Arduino IDE
- ESP32 Arduino Core
- C++

## Disclaimer

This project is intended for educational and experimental use only. It is not a certified medical device and must not be used for clinical diagnosis or hearing assessment.
